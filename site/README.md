# oc-world browser

This repository contains a static browser application. The story engine runs on the visitor's device; story databases stay in browser storage. API credentials are entered by the visitor and are excluded from archives. There is no application server or cloud story database.

Use a modern browser, keep the page open during generation, and export an archive for backups. Opening and reading saved chapters does not call a model.

The included bookshop is an original example. Imported worlds are stored only on the visitor's device. Application code is distributed for this website; no independent open-source license has been selected. Third-party runtime notices: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
